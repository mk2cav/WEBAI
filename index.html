Mixture of Experts on WebGPU

Runs the com.microsoft.MoE kernel from the Hugging Face Hub in your browser with @huggingface/kernels, then checks the result against a CPU reference.

How it works

  1. Router. Each token has one logit per expert. The kernel applies softmax and keeps the top-k experts.
  2. Experts. Each chosen expert is a small feed-forward network: act(x·W1 + b1) · W2 + b2, with an optional gate ⊙ (x·W3 + b3).
  3. Mix. The expert outputs are summed, weighted by their routing probabilities, which are renormalised to sum to 1 if you enable that.
